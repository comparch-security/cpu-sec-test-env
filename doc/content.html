cpu-sec-test-env — Documentation

This repository builds and runs the cpu-sec-bench security benchmark on every supported architecture from a single tree. The benchmark itself lives in the benchmark/ git submodule, consumed read-only at the commit pinned in env.sh: every change a lane needs is an environment change here, never an edit inside the submodule. One consumed exception: the riscv64-nemu venue's own build-corpus.sh swaps its derived registry over the tracked configure.json for the build's duration and trap-restores it — the lane never authors an in-submodule change, and its preflight and post-assert guard that swap.

For installation and first-run instructions see README.md. For the design record — every implementation cycle, its plan and its findings — see plans/.
